# Zennith Watch Store

A simple premium watch-brand assignment website built with HTML, CSS and JavaScript.

## Included
- Responsive premium UI
- Zennith logo
- Collection/product cards
- Product details modal
- Cart
- Demo checkout/payment-gateway UI
- Dark/Light mode
- Subtle CSS 3D hover effects
- Contact form UI
- Demo admin dashboard
- LocalStorage for cart, theme and demo orders

## Important: Real Payment Gateway
The current checkout contains a **demo payment gateway flow** so the assignment can run without private merchant credentials.

For real payments, connect a payment provider through a secure backend/serverless function and add the provider's secret keys as environment variables. Never put private payment keys in `script.js`.

## Run
Open `index.html` in a browser.

## GitHub
Create a GitHub repository, upload all project files/folders, and commit.

## Netlify
1. Log in to Netlify.
2. Add new site / Import an existing project.
3. Select your GitHub repository.
4. Build command: leave empty.
5. Publish directory: `/`
6. Deploy.

Because this is a static site, no build step is required.
